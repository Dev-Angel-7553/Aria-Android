Aria

Unofficial Yandex Music client with word-by-word lyrics.

AndroidAPK, Android 8.0 and newer
Linuxtar.gz with its own Java
Windowszip, unpack and run Aria.exe

What it does

  • Karaoke lyrics: the active line stays put, the text fills in as it is sung
  • My Wave, collection, search, playlists, offline cache
  • Quote cards for stories, listening statistics, CSV export
  • Listens count in Yandex, the wave learns from skips
Not affiliated with Yandex. You need a Yandex Plus subscription of your own.
